# 配送CSV変換ツールの使い方

メディボットからダウンロードした配送CSVを、B2クラウド（ヤマト運輸）にそのまま取り込める形に自動変換するツールです。
これまで手作業で行っていた「固定値の入力・お届け予定日の設定・住所とマンション名の分割・メールアドレスの検索」がすべて自動になります。

- 作業時間の目安: **5分以内**（従来 30〜60分）
- **ExcelでCSVを開く作業は不要になりました**（電話番号の頭の0が消える問題も起きません）

## 事前準備（初回のみ）

- カブクリ電子カルテ（ https://kabukuri-prod.web.app ）に **Googleアカウントでログイン**できることを確認してください
- ログインできない場合はアカウント登録が必要です。平川までご連絡ください

## 毎回の手順

### 1. メディボットから2つのCSVをダウンロード

1. **配送CSV**（従来どおりのファイル）
2. **患者一覧CSV** … メディボット管理画面の「CSV出力」→「患者一覧のCSV出力」でダウンロード（ファイル名は `customers_日付_時刻.csv`）

患者一覧CSVは、メールアドレスを自動入力するために使います。

### 2. 電子カルテの「配送CSV」タブを開く

カブクリ電子カルテ（ https://kabukuri-prod.web.app ）にログインし、上部メニューの **「配送CSV」** をクリックします。

### 3. 2つのCSVをアップロード

画面に2つの枠が表示されます。**順番はどちらが先でもOK**です。

- **① 配送CSV** … 左の枠にドラッグ&ドロップ（またはクリックして選択）
- **② 患者一覧CSV** … 右の枠にドラッグ&ドロップ（またはクリックして選択）

アップロードすると数秒で自動変換され、確認画面に切り替わります。

> 患者一覧CSVの中身がインターネット上に送信されることはありません（お使いのブラウザの中だけで処理されます）。

### 4. 確認画面で内容をチェック

上部に「総件数・住所分割・メール取得・警告」の集計が表示されます。表の色の意味は次のとおりです。

| 表示 | 意味 | やること |
|------|------|---------|
| 青色のセル | 自動変換された項目 | 内容が正しいか目視確認 |
| 黄色のセル＋⚠ | メールアドレスが見つからない、またはお届け予定日が計算できない行 | 手動で入力・修正 |
| 赤色の行（クール便不可） | クール宅急便が使えない離島宛て（伊豆諸島の一部・小笠原） | 配送方法を個別に確認 |

- **住所・マンション名・お届け予定日・eメール**の4項目は表の中で直接修正できます
- 住所が分割された行は、セルにマウスを乗せると**分割前の元の住所**が表示されます。分割が正しいか確認してください
- 「1-16-4-2」のような住所は末尾が部屋番号か番地か機械では判断できないため、必要に応じて手動で直してください

> **お届け予定日について**: 北海道・中国・四国・九州・沖縄宛ては、ヤマト運輸の公式ルールに合わせて**出荷日+2日**で自動設定されます（それ以外の地域は+1日）。従来の運用と異なる場合は、セルを直接修正してください。

### 5. 確定してダウンロード

内容を確認したら **「確定してCSVダウンロード」** をクリックします。
`b2cloud_import_日付-時刻.csv` がダウンロードされるので、そのままB2クラウドにインポートしてください。

- **ダウンロードしたCSVをExcelで開かないでください**（開いて保存すると電話番号の頭の0が消え、インポートエラーになります）

## よくある質問

**Q. メールアドレスが「⚠」のままの行があります**
患者一覧CSVが古い可能性があります。メディボットから最新の患者一覧CSVをダウンロードし、確認画面の「患者一覧CSVを読み込む」ボタンから読み込み直してください。それでも見つからない場合は手動で入力するか、空欄のまま確定できます（空欄の場合、お届け予定メールが届かないだけで配送には影響ありません）。

**Q. 同じ日に何回も変換したい**
患者一覧CSVは一度読み込めば覚えたままになります。「別のファイルを選ぶ」から次の配送CSVをアップロードするだけでOKです（ページを閉じた場合は再読み込みが必要です）。

**Q. 依頼主電話番号などの固定値を変えたい**
ページ下部の「詳細設定（固定値）」から変更できます。通常は変更不要です。

## 困ったときは

エラーが出る・変換結果がおかしい場合は、Google Chatで平川までご連絡ください。その際、**画面のスクリーンショット**を添えていただくと解決が早くなります（CSVファイルそのものをチャットに添付するのは、個人情報を含むため避けてください）。
